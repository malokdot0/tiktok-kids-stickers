# TikTok Kids Stickers

Android starter app for a WhatsApp kids-and-babies reaction sticker pack.

**Build status:** GitHub Actions builds a debug APK automatically after the workflow is added. The current app is a preview shell; it does not yet install stickers into WhatsApp. That requires a complete set of transparent WebP images and WhatsApp sticker-pack integration.

## Get the APK
1. Open the **Actions** tab.
2. Open the **Build Android APK** run after it completes.
3. Under Artifacts, download **TikTokKidsStickers-debug-apk**.
4. Extract the ZIP and install `app-debug.apk` on Android.

This is a debug APK for sideloading, not a Play Store release.
